# Simple_Distributed_Crawler_System_Project
简易分布式爬虫系统项目

实现一个简易分布式爬虫系统。
爬虫系统是搜索引擎领域中很关键、很基础的构件，能够将海量的网页数据下载到本地，进行数据处理后存储和索引以满足不同的使用场景。互联网中的网页是海量的，如何能够进行高效的数据爬取是爬虫系统面临的最大挑战之一，一种可行的方式是采用分布式的方式来进行数据爬取以提高爬取效率。
在前面的课程中我们学习了流式计算框架 Flink、典型的资源管理和调度系统、各具特色的大数据存储系统（如：HDFS、HBase等），这些知识为实现分布式爬虫系统提供了坚实的理论基础，这些典型系统也是实现分布式爬虫系统的重要组件。例如：通过流式计算框架实现 URL 的管理，通过设计合理的调度框架和调度策略实现 URL 的高效分发，通过大数据存储系统对爬取的数据进行高效存储和索引。
通过本实践项目一方面可以学以致用，将学习到的知识灵活应用到工程实践中，另一方面可以举一反三，在工程实践过程中深层次体会大数据系统的设计思想并将这些思想灵活运用到不同业务场景。
1.2 项目目标
简易分布式爬虫系统整体功能拆分到三个级别，完成对应级别的功能能够获得对应权重的基础分数，请大家务必做好团队分工与协调。

 项目要求
1. 简易分布式爬虫系统友好性要求
  1. 系统实现必须要遵守 robots 协议，包括：爬虫禁抓协议和网页禁抓标记；
    1. 爬虫禁抓协议（Robot Exclusion Protocol）：robots 协议是国际互联网界通行的爬虫规范，由网站所有者配置一个文件：robots.txt，这个文件指明了哪些目录下的网页是不允许爬虫抓取的，对于这些目录爬虫不能爬取。例如下面是掘金网的 robots.txt 文件；（https://juejin.cn/robots.txt）
[图片]
    2. 网页禁抓标记（Robot META tag）：一般在网页的 HTML 代码里有 meta name = "robots” 的标记，content 字段标明不允许爬取的行为。若以 noindex 作为标记则告知爬虫不要索引该网页内容，若以nofollow 作为标记则告知爬虫不要抓取网页所包含的链接。
禁止索引网页内容
<meta name="robots" content="noindex">
禁止抓取网页链接
<meta name="robots" content="nofollow">
  2. 系统实现必须要控制对访问网站的访问频率，避免对被爬取网站服务器造成影响；
  3. 系统实现不得对加密参数进行逆向破解；
  4. 系统实现不得抓取含有个人信息字段的数据；
2. 简易分布式爬虫系统设计要求
  1. 系统必须要以分布式思想为基础进行设计，分布式思想在系统中的体现将会对项目评分有较大影响；
  2. 系统设计时尽量使用课程所学系统进行相关模块设计；
3. 简易分布式爬虫系统实现要求
  1. 先实现一个具备基础功能的完整系统，之后在此基础上不断进行优化迭代，系统完整度也对评分有较大影响；
  2. 编程语言不限，但代码实现要遵循设计模式，代码结构清晰，关键代码需要进行详细注释；
4. 简易分布式爬虫系统结业项目答辩汇报文档

说明
基础功能
（必须）
1. 在遵守 robots 协议的前提下，实现 Web 站点网页数据爬取、存储和检索。系统至少需要具体如下功能：URL 管理、URL 分发、数据爬取、数据解析、数据存储和索引、数据查询。具体模块如下：
  1. 种子 URL 管理模块：进行种子 URL 的管理；
  2. 待爬取 URL 管理模块：基于流式计算框架管理所有的待爬取的 URL；
  3. URL 分发模块：将待爬取的 URL 按照一定策略分发给不同的爬虫；
  4. URL 分发策略：至少实现两种 URL 分发策略；
  5. DNS 解析模块：将 URL 地址转换为网站服务器对应的 IP 地址；
  6. 数据爬取模块： 进行网页数据爬取下载；
  7. 数据解析模块：针对爬取的网页数据进行清洗、文本分词等；
  8. 数据存储模块：将解析好的数据按照一定格式进行存储并构建索引；
  9. 数据查询模块：可以进行所需数据的查询；
  10. 随机 IP 代理库：反反爬虫；
  11. 爬虫进程（或节点）监控：监控爬虫运行时的状态信息；
2. 系统关键模块（URL 分发、数据爬取、数据解析）要基于分布式思想进行实现，在单机上实现多进程并发爬取；
  1. URL 分发模块要基于分布式思想进行实现，其按照一定分发策略将爬取任务分发给各个爬虫，并与各个爬虫间保持通信及时获取爬取任务执行状态；
  2. 数据爬取模块要能够实现并行爬取；
  3. 数据解析模块要能够实现并行数据解析；
